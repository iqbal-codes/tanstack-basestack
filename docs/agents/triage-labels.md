# Triage Labels

The `triage` skill moves issues through a state machine using these five labels:

| Label | Purpose |
|---|---|
| `needs-triage` | Maintainer needs to evaluate and classify the issue |
| `needs-info` | Waiting on the reporter for more details or clarification |
| `ready-for-agent` | Fully specified — an AFK agent can pick it up with no human context |
| `ready-for-human` | Needs human implementation or judgment |
| `wontfix` | Will not be actioned |

When creating these labels in GitHub, go to the repo's Issues → Labels page and add each one.
